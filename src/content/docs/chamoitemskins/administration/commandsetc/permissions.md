# Default to everyone

These permissions will be handed to everyone, unless you disable them in your permissions plugin

### `chamoitemskins.use`

Allows using the /skins command

# Default to OP

These permissions will be handed out to OPs, unless you enable the permissions on other users in you permission plugin

### `chamoitemskins.use.others`

Allows using the /skins command on other people

### `chamoitemskins.admin`

Allows using admin features

### `chamoitemskins.admin.editor`

Allows opening the admin editor

### `chamoitemskins.admin.reload`

Allows using /reload

### `chamoitemskins.admin.give`

Allows using /give

### `chamoitemskins.admin.access.revoke`

Allows using /access revoke

### `chamoitemskins.admin.access.give`

Allows using /access give

### `chamoitemskins.admin.migrate`

Allows using /migrate (plugin)

### `chamoitemskins.admin.help`

Allows using /skinsadmin help

### `chamoitemskins.update`

Get the plugin update notification
