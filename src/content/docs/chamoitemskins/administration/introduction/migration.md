We allow users of other plugins to migrate to ChamoItemSkins. We currently support migration for these plugins:

- [HMCWarps](https://www.spigotmc.org/resources/%E2%9C%85-1-20-4-26-2-%E2%9C%A8-hmcwraps-%E2%9A%99%EF%B8%8F-custom-skins-colors-for-tools-and-armor-%E2%AD%95-nexo-itemsadder-ready.107099/)

## HMCWarps

Migration from HMCWarps is pretty straight forward. You just need to run HMCWarps with ChamoItemSkins and then run
`/skinsadmin migrate hmcwarps`. It will give you info for every part of the process. If you find any errors please
report them to our GitHub issues. Not all things may be migrated correctly or at all. If you believe any part is missing
create a GitHub issue.
