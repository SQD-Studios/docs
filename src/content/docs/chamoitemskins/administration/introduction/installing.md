Installing _ChamoItemSkins_, is simple an any other plugins.

## Dependencies

| Dependency     | Is Required |
|----------------|-------------|
| PlaceholderAPI | No          | 
| HMCWarps       | No          |
| Nexo           | No          |

You also need Java 25+ and Paper or fork (Not Spigot)

### Installing

1. Download the jar from your choice of redistribution platform (GitHub, Modrinth)
2. Put the jar in your plugins directory
3. Restart the server (Do not use PlugMan(X) or the Bukkit Reload Command)
4. It's done!
