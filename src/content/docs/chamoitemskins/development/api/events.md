title: "Events"
description: "Learn about our events"

:::note

All the events here are cancellable and they are all player events, that means you can get the player which the action
revolves around

:::

### `SkinEquipEvent`

You can get the skin using:

```java
Skin skin = event.getSkin();
```

### `SkinGrantEvent`

You can get the skin using:

```java
Skin skin = event.getSkin();
```

You can get the source (COMMAND, NOTE, Bundle) using:

```java
String source = event.getSource();
```

### `SkinRevokeEvent`

You can get the skin using:

```java
Skin skin = event.getSkin();
```

### `SkinUnequipEvent`

You can get the skin using:

```java
Skin skin = event.getSkin();
```
